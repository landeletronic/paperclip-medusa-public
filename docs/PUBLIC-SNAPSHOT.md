# Snapshot público sanitizado

Este repositório é publicado sem histórico Git a partir de uma cópia revisada do repositório privado.

Foram removidos:

- registros operacionais datados em `logs/`;
- planos internos, pesquisas operacionais e runbooks;
- bootstrap específico do host principal;
- caminhos locais, nomes de máquinas e endereços privados.

Os arquivos `README.md` das pastas de logs são mantidos apenas para documentar a estrutura esperada.
